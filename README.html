Choix éditoriaux

  • Ton « Engagé & humain » retenu : ancrage RSE fort, témoignages clients, photos d'équipe attendues, langage direct sans jargon corporate.
  • Triple objectif assumé : crédibilité B2B (donneurs d'ordres) + attractivité RH (équipes) + génération de leads (tertiaire / PV).
  • Charte graphique officielle ECS (juillet 2025) appliquée : vert #00A65D, noir #000000, blanc #FFFFFF exclusivement. Typo Poppins pour titres et UI (italique 900 pour le logo, comme la signature ECS) + Segoe UI pour le corps de texte. Logo SVG reprenant la signature « ENERGIE / CÔTÉ SUD » avec éclair vert.

Usage prévu de cette maquette

Cette maquette HTML cliquable sert deux usages immédiats : (1) joindre une preuve visuelle au cahier des charges pour la consultation agence (3-4 agences pressenties), pour ancrer la direction artistique attendue ; (2) servir de support de discussion au CODIR de juin 2026 sur l'arbitrage CMS (JAMstack vs Webflow Enterprise vs autre).
